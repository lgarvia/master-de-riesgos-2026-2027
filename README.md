# 🏛️ ICADE - Máster en Riesgos (Curso 2026-2027)

Bienvenido al repositorio oficial del **Máster en Riesgos** de ICADE (Comillas).

Este repositorio está diseñado para actuar como un **Vault de Obsidian** completo e interactivo, combinando teoría cuantitativa, manuales metodológicos, simuladores web interactivos y scripts de análisis en Python.

## 📂 Estructura del Repositorio

* **`00 - Bienvenida y Guias/`**: Manuales de formato Markdown, Obsidian, visualización gráfica con Mermaid e introducción a Antigravity AI.
* **`01 - Conceptos Fundamentales del Riesgo/`**: Fichas teóricas interconectadas sobre Riesgo de Crédito, Mercado, Operacional, VaR y Pruebas de Estrés.
* **`02 - Sesiones Semanales/`**: Registro cronológico de las clases, apuntes y discusiones organizadas por fecha.
* **`03 - Laboratorio y Codigo/`**: Herramientas ejecutables, incluyendo simuladores web interactivos (`.html`) y scripts de auditoría en Python con lanzadores (`.bat`).

---

## 🚀 Cómo Usar Este Repositorio

### 1. Como Base de Conocimiento en Obsidian
1. Abre **Obsidian**.
2. Selecciona **"Abrir carpeta como almacén" (Open folder as vault)**.
3. Elige esta carpeta: `Repo GitHub - Máster de Riesgos - 2026 -2027`.
4. ¡Listo! Pulsa `Ctrl + G` para explorar la red de conceptos interconectados.

### 2. Ejecución del Laboratorio de Riesgo
- **Simulador Web:** Abre `03 - Laboratorio y Codigo/simulador_riesgo.html` con cualquier navegador (Chrome, Edge, Firefox).
- **Backtesting en Python:** Ejecuta con doble clic `03 - Laboratorio y Codigo/ejecutar_backtesting.bat`.
